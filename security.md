# Repository Security Statement

## Intended Users
This repository is primarily intended for myself and my professor to access and review coursework, code, and other assignments completed for this class.

## Security Risks
Since this repository is mainly used for educational purposes, I consider the overall security risk to be relatively low. The code and files are not intended to contain personal information, passwords, or other sensitive data. However, unauthorized changes to the repository could still affect the accuracy or integrity of my assignments.

## Security Measures
I use GitHub's account authentication and repository access permissions to help protect my work. I also avoid uploading sensitive information such as passwords or API keys. Since I am the primary contributor to this repository and it is used for coursework, I do not believe additional security measures such as a CODEOWNERS file or pull request rulesets are necessary at this time. If the repository were used for a larger project involving multiple contributors, I would consider adding these protections.
